API Reference

SnapOG generates beautiful Open Graph images at the edge — one GET request, globally cached, no setup required.

Overview

The SnapOG API is a simple REST API that generates OG images (1200×630 px PNG) via a single GET request. All parameters are URL query strings — no JSON body, no SDK required.

Base URL:

https://snapog.dev
Edge-cached by default. Every OG image is served from Vercel's global edge network. Identical parameter sets return the cached image — no re-render cost.

Authentication

Free-tier requests need no authentication — just add your query params and call the endpoint. Paid-tier API keys unlock higher rate limits.

Free tier (no auth)

GET /api/og?title=Hello+World

Paid tier (Bearer token)

GET /api/og?title=Hello+World
Authorization: Bearer sk_pro_eyJhbGciOi...

API keys are delivered via email after checkout. They are prefixed sk_pro_ or sk_business_. Keep your key secret — it controls your rate limit identity.

Quick Start

No signup required for free tier. Paste this in your browser or terminal:

# Generate a basic OG image
curl "https://snapog.dev/api/og?title=Hello+World" --output og.png

# With description and custom accent colour
curl "https://snapog.dev/api/og?title=My+Product&description=The+best+tool&bg=0D1117&color=C8FF00" \
  --output og.png

Use it as an <img> src, set it as <meta property="og:image">, or embed it anywhere images are accepted:

<!-- In your HTML head -->
<meta property="og:image"
  content="https://snapog.dev/api/og?title=My+Page&description=Short+description" />

GET /api/og

Generate a 1200×630 Open Graph image. Returns image/png.

GET https://snapog.dev/api/og
Parameter Type Default Description
title required string — Main heading text. Up to ~80 chars; font size scales automatically.
description optional string — Subtitle text rendered below the title.
bg optional hex string 07070F Background color. 3 or 6-character hex, without the #.
color optional hex string C8FF00 Accent / highlight color. Used for decorative elements and title emphasis.
logo optional URL — Absolute URL of a PNG/SVG logo to embed in the top-left corner.

Example Response

Returns a PNG image (binary). Content-Type: image/png. Cache-Control: public, max-age=86400, stale-while-revalidate=604800.

Code Examples

// JavaScript — fetch as blob
const params = new URLSearchParams({
  title: 'Ship Fast, Learn Faster',
  description: 'My weekend project',
  bg: '0D1117',
  color: 'C8FF00',
});
const url = `https://snapog.dev/api/og?${params}`;

// Use directly as og:image
document.querySelector('meta[property="og:image"]').content = url;
# Python — download to file
import requests, urllib.parse

params = {
    "title": "Ship Fast, Learn Faster",
    "description": "My weekend project",
    "bg": "0D1117",
}
r = requests.get("https://snapog.dev/api/og", params=params)
with open("og.png", "wb") as f:
    f.write(r.content)

GET /api/usage

Check your current usage and remaining quota for the billing month.

GET https://snapog.dev/api/usage

Pass your API key in the Authorization header for paid-tier usage. Without auth, returns free-tier usage keyed to your IP.

Response

{
  "tier": "pro",
  "used": 142,
  "limit": null,        // null = unlimited
  "remaining": null,
  "reset_at": "2026-10-01T00:00:00.000Z",
  "customer_id": "cus_abc123"
}

GET /api/health

Liveness check. Returns 200 when all critical services are configured, 503 if degraded. Use this for uptime monitoring.

GET https://snapog.dev/api/health

Response

{
  "status": "ok",          // "ok" | "degraded"
  "service": "snapog",
  "version": "1.0.0",
  "uptime_ms": 2341,
  "timestamp": "2026-09-07T12:00:00.000Z",
  "checks": {
    "stripe": "ok",
    "jwt": "ok",
    "kv": "ok"        // "ok" | "missing" | "error"
  }
}

POST /api/checkout

Create a Stripe Checkout session to upgrade to Pro or Business. Redirects to Stripe-hosted payment page.

POST https://snapog.dev/api/checkout
Body (JSON)TypeDescription
plan required string "pro" or "business"
email optional string Pre-fills email on Stripe checkout page.

Response

{ "url": "https://checkout.stripe.com/pay/cs_live_..." }

Rate Limits

Rate limits are enforced per calendar month and reset on the 1st of each month (UTC).

Free

500

requests / month
No API key needed — keyed by IP.

Pro

∞

Unlimited requests
sk_pro_... key

Business

∞

Unlimited requests
sk_business_... key

429 — Rate limit exceeded. The response includes X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset headers. Upgrade to Pro to remove free-tier limits.

Error Codes

StatusCodeMeaning
200 — Success — PNG image returned.
400 missing_title title parameter is required.
401 invalid_key Bearer token is malformed or expired.
429 rate_limited Monthly quota exceeded for this tier.
500 render_error Internal rendering error — retry with backoff.

Error body format

{
  "error": "Rate limit exceeded. Upgrade to Pro for unlimited access.",
  "upgrade_url": "https://snapog.dev/#pricing"
}
